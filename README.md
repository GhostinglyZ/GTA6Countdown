# GTA VI Countdown

A fan-made countdown page for Grand Theft Auto VI (launch: November 19, 2026), with tabs for launch week, overview, cast, world, music, videos, editions, platforms and FAQ.

- Single file: `index.html` (images are embedded, no build step)
- Live version: enable GitHub Pages (Settings → Pages → Deploy from branch → `main` / root)

Not affiliated with Rockstar Games or Take-Two Interactive. Artwork and logos belong to their owners.
